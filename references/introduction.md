# 研究定位、摘要与引言

## 1. 题名、摘要与关键词

- 总题名准确覆盖研究对象和核心问题，不因局部润色擅改；关键词与核心构念一致。
- 题名可采用关系/形态直述、研究问题或有实质张力的引题，不把某一种句式、冒号或词数当学术规范。先判断现题是否准确，再决定是否精炼；不因找到不同写法就认定旧题错误。
- 优先保留核心构念和最有辨识度的发现；情境、理论、中介与调节仅在构成主要贡献或限定结论对象时入题，不把完整模型和样本说明全部堆入题名。
- 非线性形态是核心发现时可直接点明。张力式引题须与实际证据相符；双刃剑不自动等于倒U形，不以标题暗示未测机制、因果识别或鼓励某种行为的最优建议。
- **先回答问题，再组织文字，最后定稿。** 以“现实问题 → 学术研究 → 实证发现 → 回到现实决策/治理”为主线；先用清楚语言提炼答案，再写学术英文，不逐句硬译。摘要须与最终全文的问题、设计、发现和价值一致。

### 八问构思与证据取舍

| 构思问题 | 摘要承担的任务 |
|---|---|
| 为什么值得研究？ | 点明具体现实矛盾及其后果，少写宏大背景 |
| 研究X与Y的什么关系？ | 明确问题、理论解释角度与关系对象 |
| 核心答案是什么？ | 优先报告主要方向或非线性形态 |
| 什么条件下更强/弱？ | 交代关键调节，明确改变哪条路径及何种响应 |
| 为什么发生？ | 用有证据的中介/机制回答，不罗列路径代码 |
| 哪种类型或场景更明显？ | 选择有认识增量的异质性，不穷举分组 |
| 还有何种深层特征？ | 按证据选择阈值、非对称性、持续性或其他深化发现 |
| 理论与实践价值是什么？ | 说明新增理解及对应的具体决策用途，回扣开头问题 |

### 组织与取舍

- 八问是构思清单，不是八句或每篇必备八项；调节与分组异质性避免重复，深层特征也可已包含于主发现。时间演进仅在实际动态证据支持时写，不能由静态曲线推断。
- **补研究依据：** 问题之后、发现之前简要交代样本/期间/规模及关键设计；必要测量定义按研究重点取舍，口径真实，不堆算法、全部控制或FE细节。
- 常用成文顺序为“现实矛盾与问题 → 理论与数据/设计 → 核心答案 → 机制及关键条件 → 具体价值”。机制与调节按逻辑调整顺序，不机械服从问项顺序。
- 主发现必须突出；机制、调节优先服务主线；异质性、深层特征及稳健性总结仅在重要且篇幅允许时进入。不为填满清单恢复撤下分析或写未检验内容。
- 陌生核心概念在首次出现时用简短、可理解的定义命名，再进入研究问题；不能先用近义描述铺垫，随后无衔接跳到专业标签。定义与实际操作化一致，不额外推断意图。
- 写清方向、形态、对象和路径，不以“存在关系”或系数分解替代含义。
- 不堆系数、p值、表号、引文、技术诊断或限制清单；是否引用、结构、字数与专门管理意义栏按当前期刊要求，不沿用旧刊限制。独立管理意义栏承担详细行动建议时，摘要不重复展开。


### 末句：认识增量与现实回扣

- **从发现推进到价值。** 说明研究增加了什么理解，或有助于哪类具体决策；不再列一遍方向、中介与调节，也不用空泛enriches the literature/offers implications收尾。
- **与开头的问题闭合。** 现实困惑引入时，末句回到相应治理议题或决策用途；实践价值不是另加与发现无关的政策口号。
- **具体到议题，适度保留层次。** 点明信息核验、资源配置等实际决策对象即可，执行步骤、信息来源及多主体分工留实践启示，不把末句写成压缩行动清单。
- **按主线选择学术、实践或兼顾两者。** 不强凑双重价值；价值也可由最后两句共同承担，检查整个收束而非孤立末句。理论贡献表述须有实际增量，采用理论不自动意味着扩展理论。


## 2. 引言

### 段落功能与衔接

管理学和商科实证论文的引言默认按以下六段起草。每段回答一个主要问题，上一段的落点为下一段提供起点。目标期刊体例或研究复杂度需要调整时，可合并或拆分，保留各项功能及论证顺序。

1. **界定研究现象。** 从要解释的具体矛盾倒推所需背景。交代现象如何出现、涉及谁，以及核心概念指什么。研究涉及策略行为时，按论证需要区分行为动机、使行为成为可能的条件，以及外界凭什么判断。概念定义在此交代，操作化留到研究设计或结果预告。
2. **说明现实后果。** 写清现象怎样通过具体行动、过程或条件关联到研究结果。同一主体既评价现象又参与决定后果时，从其判断写到实际选择，再交代该选择如何影响结果。结果依赖多个条件时，明确当前条件的作用范围。段末用一个具体的现实问题承接下一段的文献对照。
3. **对照最接近的研究并提出研究问题。** 用最相关且已核实的证据承接现实问题。核对原文的变量构造、比较对象和结果，按实际范围区分平均关联、组间差异和区间内的边际关系。指出尚未回答的问题，并把理论直接用在研究对象上，解释为什么可能存在不同答案。涉及关系反转时，简述哪些力量会随条件变化、为什么可能改变边际响应。段末提出与实际测量和设计一致的研究问题。完整的主效应、机制和边界条件推导集中放在[理论与假设](theory-hypotheses.md#2-不同关系怎样推导)部分。
4. **解释研究情境与样本选择。** 从研究问题过渡到样本与期间，说明为什么该情境适合回答问题。样本选择涉及多个层级时，分开论证各层级提供的条件，如制度环境带来哪些可观察差异，行业或群体特征为何使所研究的机制可能发挥作用。按命题引用直接支持的证据。把样本选择理由与变量的观察或匹配方法分开说明。
5. **交代核心测量并预告结果。** 核心指标可在本段开头或设计段简述一次，将文献归属写在实际借鉴的构造思路旁。先用主要发现回答第 3 段的问题，再报告有证据支撑的机制与边界条件。调节要明确作用路径和所改变的响应。只选能深化主发现的异质性和稳健性证据，并在各发现句写清其适用样本或区间。完整计算、估计和检验留给方法与结果。
6. **说明对已有文献的贡献。** 每项贡献交代与哪项既有认识对话、本文的哪项证据推进了理解。结果预告负责呈现研究发现，贡献段负责说明这些发现补足了哪个已有解释或适用条件。每项贡献沿用其对应的研究对象和证据范围。

### 贡献的分段、篇幅与验收

- 贡献默认合写一段，三项贡献可用 First、Second、Finally 保留层次。每项先点明要推进的认识，再给出准确的文献对照和具体增量。篇幅或论证复杂度需要时，可按贡献拆成短段。数量和排序由证据决定，逐项引文要求见[理论贡献](discussion.md#2-理论贡献兑现引言缺口)。
- 三项贡献合写可先按约 200 个英文词起草，再按证据和期刊要求调整。精简时优先删重复铺陈，保留每项贡献的文献比较基准和新增认识。
- 与讨论按贡献逐项核对同一文献问题、增量、作用对象与证据范围；引言交代新增认识，讨论解释发现如何补充已有认识。段数相同不构成重复，逐句换词重述才是问题；详细区别沿用讨论规则。
- 交付前逐段核对段落功能、关键论断、支持该论断的来源和证据范围。优先处理相邻段落的重复、引文与论断错位及超出结果的表述，再核实际字数、引用域及分页。具体论文段落、计词与核验记录留项目，skill 只保留抽象方法。
