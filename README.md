# Empirical Paper Writing · 实证论文写作

**Empirical Paper Writing 是为管理学与商科定量研究设计的 Codex 写作技能。** 它帮助作者从文献中提出问题，用实证结果回答问题，再向读者解释这个发现为什么值得关注。

写学位论文或期刊初稿时，可以从一段草稿和几篇相关原文开始，也可以把一个假设和一张最终回归表写成英文结果段。团队合稿时，可以沿着同一个构念，从摘要一路核对到附表。这套写法适用于用调查数据、档案数据或实验数据检验变量关系的研究。

## 你的论文写到哪一步了？

| 手头的任务 | 交给技能的材料 | 可以得到什么 |
| --- | --- | --- |
| 写题名、摘要或引言 | 研究问题、最接近的几篇研究、主要发现 | 围绕核心发现拟题，把研究动机、证据和贡献写成一段能独立阅读的摘要。在引言中交代前人已经回答什么，以及本文进一步回答什么。[题名、摘要与引言](references/introduction.md) |
| 整理文献、推导假设 | 相关原文、构念定义、待解释的关系 | 按研究问题归类，用每项研究实际测量的指标说明发现。再从理论前提出发，交代谁在什么条件下改变了行为，以及为什么预期结果会随之变化。[综述与假设](references/theory-hypotheses.md) |
| 交代样本和变量 | 样本筛选记录、变量定义、测量来源、模型设定 | 说明每一步筛选如何改变样本，把指标选择、观察窗口和合成方法分别归给相应来源，并写清本文做了哪些调整。[研究方法](references/methods.md) |
| 解读回归和补充检验 | 最终结果表、图、表列说明、对应假设 | 将系数还原为研究对象的变化，说明结果支持假设的哪一部分。中介分析写清传递路径，调节分析写清哪段关系发生变化，稳健性分析按各项检验回答的问题组织。[实证结果](references/results-writing.md) |
| 写讨论、贡献和实践启示 | 核心发现、可比研究、实际决策场景 | 核对最接近研究的主分析与附表，把贡献落到一个具体差别上。实践启示写明谁可以依据哪一项发现，调整什么决策。[讨论与结论](references/discussion.md) |
| 合并 Word 主稿和补充材料的修改意见 | 当前稿件、图表、引用及需要处理的批注或页面 | 按指定范围修订，配合文档工具检查 Zotero 引用域、图表编号及跨页衔接。长表续页时，核对表头能否辨认、系数与对应统计量能否一起读到。[图表与注释](references/figures-tables-notes.md) · [Word 排版](references/word-layout.md) |

## 整篇论文共用的写作标准

**同一构念用同一个名称。** 研究团队选定术语后，标题、假设、变量定义、图轴和附表都沿用这个名称或约定的缩写。审阅时会逐处判断近义词指向的对象，也会保留量表原名和直接引语。多人分工写作时，读者仍能从理论推导认出结果表里的同一个变量。[全文用语规范](references/chapter-writing.md)

**每条引用都有具体的归属。** 一句话可能同时写到前人的测量方法和作者自己的分组决定。技能会把引文放到借用的方法旁，再交代本研究怎样分组。核查贡献时，还会回到原文的机制检验和相关附表，确认已有研究走到了哪一步。[文献与证据核验](references/evidence-and-delivery.md)

**修稿经验可以带到下一篇论文。** 遇到值得复用的改法，可以让技能把它提炼为通用规则，补进对应章节。论文里的原句、数据和具体案例留在各自项目，需要示范时另拟独立情境。[写作经验维护](references/learning-and-maintenance.md)

## 安装与第一次使用

在 Codex 中发送下面这句，即可通过技能安装器安装仓库根目录的技能。

```text
请用 $skill-installer 从 https://github.com/xiaofei03/empirical-paper-writing 安装根目录的技能，安装名为 empirical-paper-writing。
```

安装后，在论文项目中输入 `$empirical-paper-writing`，附上需要处理的材料。可以用中文讨论并指定英文正文，也可以先要审阅意见，再决定怎样改稿。下面三句话可以直接使用。

> $empirical-paper-writing 请读我提供的三篇原文和引言最后一段。逐项列出前人已检验的关系、本文新增的发现，并给出一版英文贡献段。

> $empirical-paper-writing 请根据我附上的结果表改写稳健性检验。把回答同一个问题的列放在一起，保留表列号，用中文说明每组检验解决了什么疑问。

> $empirical-paper-writing 请通读主稿和附表，找出同一构念出现多种英文名称的地方。按位置列出原词、建议用词和判断依据，先给我清单。
