# 图表、注释与附件

## 1. 信息分工

| 位置 | 任务 |
|---|---|
| 图题/表题 | 简短点明对象或分析类型 |
| 图例/轴/面板/列名 | 变量、分组、单位及展示对象 |
| 图注 | 尚未标清的阴影、线条、符号或特殊编码 |
| 表注 | 括号统计量、星号、未标明的特殊设定 |
| 正文 | 目的、关键发现、含义与假设回应 |
| 方法 | 构造、估计、中心化、样本与预测设定 |

信息已有位置，不换个位置再写一遍。精简前先核信息确实存在，不能让N、必要FE或推断设定随删注消失；优先补进表体。

## 2. 标题与正文呼应

- 题名短且具体、大小写/编号/标点统一；如“Moderating effect of W”，不以“on M”暗示W直接作用M。
- 主表、完整附表及合表后的列号一一对应；中介与单一调节优先合表的条件见[结果细则](results-writing.md#5-调节)。
- 主文表图在相应段解释用途或模式，题注不算正文呼应。表给精确系数、图展示关系，不重复两套数值；补充材料按需要短引。
- 文献对照附表的短引嵌入已有研究总结，不必另写一句表格介绍。被用作证据的附表准确定位，同类材料可合并短引，词典或变量定义可整体指向附录；区分期刊要求引用补充文件与逐张附表独立介绍，不把后者设为通用规则。移动表格引用时保留相邻文献活域，新增文字放在域外。
- 不在题注写AI辅助绘图等制作过程。全文级声明按用户及期刊要求单独处理，不随删图注自动删除。

## 3. 图注：只解码必要信息

- 默认一句、必要时再补；这是精简目标，不是期刊硬性字数。图例已有组别/取值、轴已有单位、面板已有含义时不重述。
- 阴影一般只需说明区间；pointwise、聚类层级、N、控制取均值、FE归零、预测器与绘图区间集中方法，确为读图不可缺才短写。
- 拐点数值已标则不重报；未解释的分布面板、虚线或负向柱形编码须说明。网络图说明节点、边及大小/宽度，不抄算法和样本处理。
- PSM图保留实际匹配权重、未标明的阈值或零线以下编码；异质性图保留未定义分组与缩写。不能靠长注弥补不清楚的轴，先评估轴内补清。
- 不写结果讨论、模型局限、显著区间提醒或制作流程。

短模板按真实图取用：

- `Note: Shaded areas indicate 95% confidence intervals.`
- `Note: The dashed line marks the turning point; the lower panel shows the distribution of X.`
- `Note: Nodes represent [entities]; edges represent [connections]. Node size indicates [metric]; edge width indicates [weight].`
- `Note: The matched control density uses matching-frequency weights.`
- `Note: Control-group counts are displayed below zero.`
- `Note: Dashed lines mark ±10% standardized bias; post-matching estimates use matching-frequency weights.`

组别、区间、阈值和权重仅在实际采用且尚未清楚标明时使用。

## 4. 表注：统计量与符号优先

- 普通回归用“括号统计量＋星号”，必要时一句特殊设定。核t、z或SE及实际聚类层级，不把范文口径复制到所有列。
- 表内已有N、R²、Controls及FE，注释不重复；列名/方法已交代测量、滞后、控制名单、中心化和完整方程，也不逐列复述。
- 列间推断不同、特殊尺度/变换、缩写或分组尚未定义时短写。两向聚类说明实际维度及适用列，不加通用少聚类提醒。
- 不在表注讨论IV识别、匹配结果、形状区间或结论；主文与附表用一致短模板，不复制整段方法。
- 模板：`Note: [Statistic type] are in parentheses. *** p < 0.01, ** p < 0.05, * p < 0.10.` 必要时追加实际推断说明。相关矩阵仅用适用星号，不加t值或聚类模板。

## 5. 表图成品与附件

- 回归表可编辑，曲线/网络/模型图清晰；沿用学术三线表、字体、字号及对齐，不套商务填色网格。
- 每列保留真实N和拟合统计。控制变量、固定效应或聚类层级因模型而异时，在表体按模型列对齐列示，让读者沿同一列就能核对系数及其设定。各列共有的设定可在表注中用一句话交代。复用版式时以目标模型导出逐列核对因变量和设定。
- 系数与t/SE成对，长表自然续页、重复正确列头、表尾与短注相连；词典首行若为条目不能误设重复表头。单行不拆仍须检查两行统计量是否分离。
- 模型图调节箭头指被调节路径，不指终点节点；图例、轴、面板、单位和假设一致。按精确数据排图，不拉伸比例，不以共同支撑筛选冒充匹配。
- 中文图用支持中文字体与UTF-8结构化输入，先看本体防乱码；宽表按需要横向，不擅自缩小约定字体/行距。
- 合并同类曲线为多面板时，统一比较所需坐标尺度、标签、线型和字体；使用原始精确绘图数据，不直接把两张整图缩小拼接。按最终入稿尺寸检查可读性，迁移后同步正文面板引用、附件编号及图片说明属性。
- 主文、附录、在线材料同查术语、表号/列号、注释模板、统计含义和引用。精简后按[Word排版](word-layout.md)复查受影响页，不绑定整表或重排无关章节。
