# 讨论与结论

## 1. 结论：回答研究问题

- 用必要定位句引入，概括核心关系、关键中介/调节及简短实质含义；清楚呼应已有理论，不逐表复述、不列模型和诊断、不机械重复H编号。
- 与预期一致且解释充分的发现简写。未支持、部分支持或与预期相反的关键发现，按其重要性多解释：理论预期与实际差异在哪里、哪些已有证据支持解释、留下什么问题。不以不显著推定零效应，不事后编机制或自动追加分析。
- 详略由认识增量决定，不是“全部显著就固定短、出现不显著就必须长”。不要求每个非核心系数进入结论，也不省略改变核心解释的重要发现。
- 结论呈现研究回答，理论贡献负责与文献对话。确需定位时可以引用，不重复独立贡献段；保留构念、调节对象及相关/因果范围，不添防御套话。

## 2. 理论贡献：兑现引言缺口

每项采用“已有研究的具体解释重点 → 新发现 → 增加或改变什么理解”，逐项对应引言gap。引言交代贡献定位及核心增量，讨论用发现说明其如何补充、修正或界定已有解释；区别不取决于段数、时态或固定长短比例。若两处整段互换仍无实质区别，应删重复，并为讨论补足有证据支持的理论解释，而非换词扩写。不同段回答不同解释问题，不把同一发现改换文献标签算多项贡献。

引言与讨论中的每一项贡献都必须有准确、相关的参考文献作为比较与支撑，明确“已有研究解释了什么—本文新增什么”；不能只在其他贡献或前文集中列引文，也不能把引用放在本研究发现之后充当装饰。有引文不等于有贡献，比较须指向具体认识增量；精简优先压缩重复铺陈，保留文献比较基准。两处可引用同一来源，但承担定位与深化的不同任务。

四个常用定位入口：

| 入口 | 要回答的问题 |
|---|---|
| X的后果 | 新结果、形态或条件怎样改变对X后果的理解？ |
| Y的前因 | 新解释因素怎样补充或修正Y的形成逻辑？ |
| X与Y的机制 | 理论揭示了何种传递过程，超出已有直接关系多少？ |
| 理论本身 | 修正或拓展了哪项命题、假定、机制或边界，证据是什么？ |

- 这是构思框架，不是贡献只有四类，也不要求每篇凑齐；边界条件、整合或测量的理论价值须具体论证。仅换情境、采用理论或增加一个变量不自动构成理论扩展。
- 同一X→Y发现可同时涉及X后果与Y前因，但若解释增量相同，应合写。中介不自动打开全部微观黑箱；边界研究不自动改变理论本身。
- 写每项贡献前，核对最接近的研究在主分析、机制检验、交互项及相关附表中实际检验了哪些关系。先各用一句话写清前人已回答什么、本文的证据又回答了什么。若某条路径已有检验，说明本文进一步揭示了它的哪种形态、适用条件或理论含义。仅凭方法更强或结果显著，不能认定有理论贡献。比较基准有调整时，回查引言和讨论中对应的贡献表述。
- 引文紧邻支持的前人命题；本研究承担新发现与解释。少量最相关引用即可，不反复extend/enrich，不抄系数、H编号或检验清单。

## 3. 实践启示：发现连接行动

组织为“发现的实际含义 → 明确主体与措施 → 决策用途”。建议须具体可执行，区分谁提供信息、谁判断、谁实施，不重复结论或理论贡献。

可从四类主体寻找落点：监管者的核验/监督/规则，行业组织的标准/评价/协调，企业的资源配置/流程/风险管理，投资者及其他利益相关者的信息核实/决策。按研究对象选相关主体，不强制四点；不能每篇都倡议立法、成立协会或投资决策，已有协会也不默认需要新建。

- 建议须与真实发现相连，不能删掉研究背景后仍完全通用；优先明确行动、依据和用途，避免“加强正向、避免负向”等空话。
- 合理管理推论可用建议语态，无须逐项都有干预估计；should/could/can按含义使用，不把建议写成已验证效果或必然改善。
- 保留净额、方向及决策职责；不从非线性关系建议追求“最优”失真行为。不堆泛泛政策、引用、主体或固定段数。

## 4. 局限与未来研究：说明范围，推进问题

- **以展望为重心。** 先用一句话说明现有研究设计回答了什么，或变量测量捕捉了什么，再沿这个范围提出下一步值得回答的问题。更换样本、细化观察层级或补充指标，都可以作为拓展。仅当有具体依据表明某项限制会影响结论解释时，才说明哪项推断受到怎样的限制。不要为了引出展望而主动贬低现有设计或质疑测量效度。
- 每段围绕一个问题。拓展情境时，说明换到何种情境、为什么预期关系可能不同。拓展机制时，写清谁可能作出什么反应、这种反应如何传导至结果。拓展边界条件时，指出哪个条件可能改变哪一段关系。按论文需要选取方向和段数。
- 让新数据或新方法服务于追问。提出更细的测量时，说明它能区分哪两种过程、观察哪个环节或检验哪种解释。段落写到读者能看出这项拓展会增加什么认识即可。
- 概括本文时按实际检验的模型命名变量与路径，借鉴旧稿尤其要核对中介和调节的作用对象。用 *future research could examine whether* 等措辞引出尚待检验的关系，避免把未来机制写成本文发现。
- 判断范文自然段时核PDF原版，区分跨栏、跨页、编号与实际分段。
