# 理论基础与假设

## 单列的实证文献综述

- 简要交代概念来源和本文采用的定义，再点明综述讨论的是前因还是后果。按与研究问题相关且层级一致的维度归类，例如作用对象、结果类型或关系形态，不把结果对象和解释机制混列为平行类别。先说明分类依据，再写清各类的具体研究对象及代表研究发现的方向或形态，必要时交代适用条件，不用“产生影响”等笼统措辞代替具体发现。短篇单段综述承接前段问题，将分类融入发现叙述，避免反复介绍类别或逐篇机械展开。
- 精简时先删重复背景和分类提示，保留代表研究实际测量的结果、发现的方向以及影响解读的条件。例如，研究记录的是返修次数，就写次数如何变化。概括为“产品质量改善”还需要支持这一更广结论的证据。
- 从叙述转向评价时，先核对各研究比较的是哪些对象、水平或时点。按水平比较的结果用“在较低／较高水平下”表述，实际比较了不同时期才用“初期／随后”。说明各类发现共同回答了什么、哪些差异来自结果指标或检验方式。不同结果指标上的正负关联可以同时成立。同一结果的非线性须由对应研究支持，并点明形态和方向。
- 收束时交代未解问题为何重要，并用已有证据与适用理论引出本文的问题。与引言直接对照过的研究只保留定位所需的发现，完整机制留给假设推导。

## 单列的理论综述

- 理论综述先交代读者理解后文推导所需的概念和相互关系。围绕理论的核心问题，从行动者掌握的信息写到他们如何判断、如何响应以及响应带来什么后果。以理论原文和权威综述支持各个命题，删去与论证无关的应用案例。
- 用本研究的情境简短对应抽象角色和对象。信号理论可按“信息不对称 → 发送者发出可观察的信号 → 接收者结合信息环境判断可信度 → 资源响应产生收益或惩罚成本”的顺序组织。区分接收者判断的可信度与信号实际反映属性的程度，也区分制作成本与失真被识别后产生的惩罚成本。变量关系的方向和形态在后续假设推导中说明。

## 1. 推导顺序

理论前提 → 行动者的判断/响应 → 资源或组织后果 → 变量关系 → 假设。

- 写清谁掌握什么信息或资源、据此怎样行动、为什么改变结果。每段推进一层，不在相邻段反复解释同一收益或成本。
- 每项假设先选与该关系直接有关的理论命题，再映射到具体行动者、判断和响应；不能只在开头引用理论，随后改写为一般经验故事。精简前标出理论前提、情境机制与关系结论，删重复但保留这些逻辑环节，不以增加理论名称出现次数代替推导。
- 理论综述已界定的核心概念，在假设段落中沿用原术语和含义。首次写到相应判断、行为或后果时，就点明它在本研究中对应哪个概念，使关系结论能够直接调用前文已经解释的机制。补足推理时用既有概念说明判断和行动，不为扩写或安放引文引入额外构念、理论标签或旁支机制。来源采用的其他概念或解释框架不随引用带入本研究。
- 以本研究的机制为推导主线，用句末引文支撑来源直接支持的前提，另起一句承接本文的情境推论。仅在原研究的情境或发现是推理所需的直接对照时展开说明，不为保留引文另起旁枝。已有 A 与 B 的关系不等于已证明本研究的方向、机制或非线性。
- 仅用当前授权理论；不自行恢复已删理论、增加中介、竞争假设或未经测量的机制。

## 2. 不同关系怎样推导

- **主效应：** 明确X怎样改变Y及方向。非线性需解释同一过程为何随X水平变化而变号。由正向转入负向推导时，承接前段的收益及其成立条件，说明同一行动者为何改变判断或响应。采用收益与成本两股力量推导时，分别解释收益为何趋缓、成本为何增加。收束时比较边际作用并说明方向何时反转，避免重讲两段机制。
- **中介：** 分别解释X→M、M→Y及传递逻辑；净额构念不能偷换为单边流入或流出。
- **调节：** 解释W怎样改变X→Y或X→M的过程，不能仅说W本身有利或直接改变终点变量。连续调节变量可用“随着W提高”贯穿推导，按机制需要区分X的水平，不为篇章对称而机械地分写W高低两组。非线性调节明确涉及斜率、曲率、拐点或平坦化，负交互不自动表示削弱整个倒U。
- **假设：** 直接陈述对象、方向或形态，编号、方程与表图一致；编号不能替代推导。若理论未提供方向，不为句式整齐强加正负判断。

采用信号理论时，明确发送者、可观察信号、接收者、被推断的不可观察属性，以及可信度和成本依据；区分信号本身与衡量其真实性或失真的指标。低制作成本的沟通为何被采信、失真为何产生惩罚，均须解释，不能套用“成本越高越可信”。信息环境改善本身不决定关系正负或曲率变化；须说明它怎样改变对特定信号的依赖、核验或资源响应。倒U形也须另行推导收益与成本为何随核心变量变化，不由理论标签直接推出。

## 3. 与实证及讨论衔接

结果用一句前文已有机制解释发现并回应假设，不重复整段推导或写“developed in Section…”；讨论再说明理论增量。未直接测量的认知或微观行为，不能写成已分别验证的机制。
