# 研究方法：样本、测量与模型

## 1. 样本与描述口径

- 样本来源、筛选、期间、观察数及企业数可追溯。区分原始、描述、估计和匹配样本；FE单例、滞后、缺失及分组可造成N不同，一致指口径清楚，不是数字强行相同。
- 描述统计与相关矩阵优先覆盖自变量、因变量、重要中介和调节；基础构念优先，不必列每个平方/交互及替代检验变量。按篇幅和期刊实文决定主表或附表，不把个别论文惯例当硬规则。
- 选择共同样本比较规格时，须实际重算相应统计和估计，不能只改N标签；普通写作不自动授权重估。

## 2. 变量测量

- 首次交代全称、缩写、定义、公式/量表、单位、数据和测量来源、数值方向。区别原始指标、派生差值、替代测量和残差。
- 采用既有测量时，优先“Following Author (year), X is measured as…”等直接归属写法，少用we反复自指；we并非不规范，关键是不把借用写成原创。实际改编、开发或独立选择时写清本研究做了什么。
- 直接采用完整词典/量表，不把来源作者的训练、扩展和筛选写成本研究操作；改编部分单独说明，引用必须核原文。
- 将复合指标拆为指标选择、观察窗口、合成方式等实际采用的步骤，把引文放在所借用的步骤旁，另行说明本文调整或自定的步骤。若本文把前人的稳健性替代测量用作主指标，交代它在两篇研究中的用途。仅借用部分做法时，写明具体沿用了什么，避免用一句 “Following Author (year)” 笼统归属整个公式。
- 区分全样本/逐年标准化、参考样本、缩尾/截尾及处理顺序。参考样本可能早于最终估计筛选；用原构造样本的矩复现，不能仅因最终样本重算不一致就认定指标有误。
- 回归脚本只载入已有得分时，追查上游数据获取和指标构造目录；按观测标识连接原始得分与当前指标，再核公式及数值复现。相似代码或文件名不足以证明来源一致，归一化不能自动写成z-score。
- 定义与已有构造记录冲突时核来源和顺序，不能靠润色宣布已对齐；参考文献只能证明来源方法，不能代替本研究的实际构造记录，原文未给出的参数不按惯例补写。不确定处理不写成事实。净额允许负值，相对差距不直接解释为主观意图。
- 概念的方向性、代理指标的正负值和研究样本范围分别交代。标准化/排序差值的零点不自动构成真实行为的有无界限；不把负值直接认定为反向行为，也不为保留全样本而将方向性概念改成任意偏离。采用正向子样本时，说明它检验的是区间内关系；是否改为主样本由研究问题与构念一致性决定，不能仅依据显著性。
- 补统计先复现同版旧变量，再加入新变量；显式保留双精度，星号按未舍入概率生成。

## 3. 模型与程序

- 正文、方程、表格统一控制变量、固定效应、聚类、中心化和交互设定；完整非线性调节保留实际估计的XW和X²W，不能按显著性悄悄简化。
- PSM写清处理定义、支撑、实际匹配、是否有放回及频数权重；共同支撑筛选不等于匹配。
- 方法集中写推断与预测设置，后续不逐表复述。图用正式软件导出的精确数据，排图不暗中重估。
- 测量诊断、识别与稳健性各自回答不同问题；写作不自动追加或恢复撤下检验。
