# 实证结果与补充检验

## 1. 结果段共同结构

- 围绕“当前表/列及问题 → 关键证据 → 一句前文机制的实质解释 → 假设回应”组织，不强制四句。仅报系数、H编号或consistent with the theory标签都不构成完整解释。
- 直接呈现方向、形态和含义；技术集中方法，表格承载控制、常数和拟合统计，不逐项读表，不附通用防御句。
- 关键论断追溯最终证据及样本，方法、表图与正文一致。无需每个系数、每段都重复闭环，不在结果重新推导理论或新增未测机制。
- 正文按当前编号呼应图表并解释模式，不能仅写see Figure；题注不算正文引用。合表时精确到列，不把整张表误说为只报告本节分析。

## 2. 描述统计与相关性

概括核心变量的水平、离散及有意义的方向，不逐项读表；单位、N与表一致，比例、百分比、百分点和百分比变化不混写。相关矩阵不代替控制因素后的回归，也不直接支持中介/调节。

## 3. 主效应与非线性

- 选择完整规格，报告关键方向与显著性，再解释形态。倒U不能只凭负平方项断言，须核实际形状证据；仅符号一致时限定为与该模式一致。
- 拐点、区间、端点等证据集中一次，不在摘要、各稳健性及图注重复。拟合图解释两侧形态，保持静态水平表述。
- 方法引用归检验提出者，结果归本研究：先说明采用Author (year)的方法，再报告检验结果，避免“Our tests support this pattern (Author, year)”式归属不清。

## 4. 中介

- 直接称mediation/mediating role，不用potential channel回避已提出的中介。按对应列报告X→M、纳入M后的M→Y及直接关系；非线性先解释X与M的形态。
- 用前文传递逻辑解释M怎样连接X与Y，保留净额构念，不宣称已直接测量全部微观过程。
- 路径回归、部分/完全中介、间接效应区间不是同一判断。二次间接分量显著不等于每处边际间接效应显著；区间跨零不改成显著，不为润色自动补Bootstrap或恢复撤检验。

## 5. 调节

- 明确W改变X→Y还是X→M，交互项方向接实质理论解释与假设回应；摘要、推导、方程、结果、图及结论使用同一对象。
- 同时含中介与一个调节变量、模型衔接清楚时，优先合并结果表，正文仍分中介/调节小节。删新增信息少的重复过渡列，保留有实际比较用途的列；先核样本、控制和FE，不固定列数，不把合表当完整有调节中介检验。
- 完整非线性模型M=…+b1X+b2X²+b3W+b4XW+b5X²W中，b4为X=0处斜率差，b5改变曲率；中心化按实际模型。负向斜率差不自动意味着绝对效应更弱、曲线变平或拐点改变。
- 按实际规格报告一次及平方交互，不以一个显著项概括整条曲线或完整间接效应。点估计、区间和全区间结论对应，以准确范围解决，不堆提醒句。
- 高低组取值来自实际模型；双面板图简述拟合关系与斜率差，再解释模式，不移植范文分组。

## 6. 稳健性

- 以“检验目的 → 替代处理 → 方向/形态与显著性 → 对应表列”组织；顺序可按阅读逻辑调整。同类检验合并概括，不逐列复述系数和p值。
- 按测量与时间、样本与控制、固定效应与推断等实际目的分组；多项检验不等于必须拆成多个小节。组织清楚且篇幅适中时保留既有结构，不为模仿范文增加段数或机械压缩。
- 说明实际处理对象：替代测量检验测量依赖，滞后考察时间顺序，样本限制对应定义或情境，额外控制对应具体差异。固定效应吸收相应层级的未观测因素；聚类标准误允许相应维度内的误差相关，不能混写成控制了同一类冲击。
- 结果同时交代有依据的方向和显著性，非线性形态遵循前述形状证据规则。显著性水平不同，不统一声称均在某一较严格水平显著；可概括统计显著性，由表中星号和表注呈现具体阈值。用可核对的判断回扣基准发现，不用all results remain unchanged掩盖差异。
- 各组准确对应表号和列号，避免只有部分段落提供定位。借用的新测量或方法在说明处准确引用来源，不要求每项常规设定、每句结果都另加引文。
- 开头简短总领即可，避免重复罗列检验类别、具体处理和一般目的。基准理论已充分论证时，此处回扣主要发现即可，不再次推导机制；不添加通用防御句或逐项识别/少聚类提醒。

## 7. 测量诊断、PSM与IV

### 测量诊断

- 分项多项式/响应面回答构念能否压成差值，不能混称因果识别。

### PSM

- 按“可观测特征可比性的目的 → 分组与实际匹配 → 平衡证据 → 匹配样本回归及基准回应”组织；图表引用贴近相应步骤，尽量以主要发现收尾，不在结尾堆附件清单。
- 共同支撑图说明得分重叠，协变量平衡图说明特征可比性，不能互相替代。共同支撑、匹配后、频数加权不同，N与权重按真实模型；平衡图与回归使用不同权重时用短语明确，不因精简而混淆。连续变量高低分组用于匹配，不自动把后续连续或非线性回归改称二元处理效应。

### IV

- IV按“工具构造与理由 → 第二阶段关键发现 → 必要诊断”组织，也可先简述第一阶段再报告第二阶段，不把一种顺序当期刊硬规则。准确区分均值的平方与平方项的均值；保留的替代工具先介绍，不在结尾突然加入。
- 相关性理由说明工具为何关联内生变量，排除限制理由说明其为何不通过其他路径影响结果；引用分别支持相应机制，不以一般扩散或同群文献证明具体工具有效。识别所依赖的前提可用一句明确写为假设，不伪装成已验证事实，也不凭空编造经济理由。固定效应及异地构造说明控制范围，不自动证明排除限制；第一阶段强度也不证明排除限制，恰好识别不提供过度识别检验。
- IV诊断围绕其实际问题解释，不只排列缩写和数字。检验“拒绝/未拒绝”须明确原假设，不混淆内生性、弱识别稳健显著性与工具有效性；不套用不适合当前模型和误差结构的通用强度阈值。正文保留关键诊断，其余准确放表体，不以精简改写检验含义或显著性。
- 诊断放结果/相应表体，不在表注再讨论；项目撤展示安排不推广为统一删除规则。

## 8. 异质性

先交代分组依据，再报差异及含义并呼应图。一组显著另一组不显著不等于组间差异显著；一次交互、平方交互与联合检验回答不同问题。正文引用合并样本交互模型时，给出主表或补充表位置；核对共同控制斜率等设定，不把交互项直接等同于独立分组回归的系数差。标签与阈值核实际编码，子样本FE单例可使N不能直接相加。差异结论按真实证据写，不靠suggestive/only堆句。

## 9. 数字与交叉引用

数值、符号、括号统计量、星号核精确导出，按未舍入p值生成星号；0.0000不代表零。区间写清对象：系数、预测、拐点、边际效应或组差。表号、列号、面板及附录指向从当前稿读取；补充材料在需要处短引，不插清单。撤检验的依赖清理见[证据与交付](evidence-and-delivery.md#5-撤表撤检验的依赖清单)。

同类统计量在正文、表格和图中采用一致的展示精度，不同统计量按信息需要分别设定。需要增加小数位时回查同版原始结果或精确导出，不在已舍入数值后机械补零；只调整展示，不改底层估计和显著性判断。
